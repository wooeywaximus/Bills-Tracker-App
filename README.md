# Bills Tracker

Offline personal bills tracker. Your data stays on your device.

- **iPhone / web app:** open https://wooeywaximus.github.io/Bills-Tracker-App/ in Safari, then Share > Add to Home Screen.
- **Android app:** download `BillsTracker.apk` from the latest [Release](../../releases/latest) (or directly from [`android/BillsTracker.apk`](android/BillsTracker.apk)), open it and allow installs from your browser or Files app. Updates install over the old version and keep your data.
- Back up regularly from Setup > Backup.
- See [CHANGELOG.md](CHANGELOG.md) for what changed in each version.

`android/source/` holds the Android project sources. The signing key is not stored here.
